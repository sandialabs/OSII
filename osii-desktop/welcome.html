A library keeps your work

OSII reads original documents where they are. A new library stores extracted text, provenance, collections and processing state separately on local disk.

To continue existing work, choose its .osii folder. Optionally select its configuration folder to reuse model connections and settings. Stop the other OSII application first.

PDF, DOCX, PPTX, XLSX, common text formats and full-page OCR are included. Semantic search and AI answers use a model connection you can add later in Setup.

This installer does not include Java/Tika, PostgreSQL or specialist processor runtimes. Existing external processors can be connected through Setup. Dataset text extraction is included; specialist dataset analysis is separate.
